# Пульт браузера для Mirabox Stream Dock

На блоке из шести клавиш 3×2 воспроизводятся текущие кадры видео из выбранного браузерного плеера. Частота обновления до 6 кадров в секунду. Для аудио отображаются обложка, название и прогресс. Семь действий управляют воспроизведением, перемоткой на 10 секунд, громкостью плеера, выключением звука и выбором другого плеера.

Плагин предназначен для Windows, Stream Dock 3.10.188.226 или новее и браузеров на Chromium 116 или новее, включая Opera, Chrome и Edge. Расширение нужно установить в браузере, где вы смотрите видео.

## Установка в Opera

1. Полностью распакуйте ZIP. Выйдите из Stream Dock через значок в трее.
2. Запустите `install.cmd`. После сообщения об успешном копировании откройте Stream Dock.
3. В Opera введите в адресной строке `opera://extensions`. Включите **Режим разработчика**, нажмите **Загрузить распакованное расширение**.
4. В окне выбора папки вставьте `%LOCALAPPDATA%\Noxfor63\BrowserMedia\extension` и выберите эту папку. В Chrome адрес страницы расширений — `chrome://extensions`, в Edge — `edge://extensions`.
5. Обновите открытые вкладки с аудио и видео. Запустите ролик вручную один раз.
6. Нажмите значок расширения «Медиапульт для Stream Dock», чтобы увидеть статус связи и выбрать нужный плеер.

Установка использует Node.js, встроенный в Stream Dock. Файлы расширения сохраняются в постоянную папку пользователя.

## Раскладка на панели 5×3

Добавьте шесть копий действия **Экран плеера** в прямоугольник шириной три клавиши и высотой две. Щёлкните по каждой кнопке в редакторе Stream Dock и задайте **Часть экрана** по таблице.

| | Левая | Средняя | Правая |
| --- | --- | --- | --- |
| Верхний ряд | Верхняя левая | Верхняя средняя | Верхняя правая |
| Нижний ряд | Нижняя левая | Нижняя средняя | Нижняя правая |

Ручное назначение работает и при отсутствии координат от Stream Dock. «Автоматически» объединяет заполненный блок 3×2, если программа передаёт расположение кнопок. Одиночная клавиша показывает всё изображение целиком.

На оставшиеся клавиши перетащите нужные действия из категории **Пульт браузера**.

| Действие | Результат |
| --- | --- |
| Пауза / воспроизведение | Переключает воспроизведение выбранного плеера |
| Назад на 10 секунд | Перематывает назад в доступном диапазоне |
| Вперёд на 10 секунд | Перематывает вперёд в доступном диапазоне |
| Тише / Громче | Меняет громкость выбранного аудио или видео на пять процентных пунктов |
| Звук вкл. / выкл. | Переключает отключение звука выбранного плеера |
| Сменить плеер | По очереди выбирает найденные аудио- и видеоплееры |

Выбранный плеер остаётся выбранным при переключении вкладок и паузе. При закрытии вкладки пульт выбирает другой доступный плеер. Всплывающее окно расширения позволяет выбрать плеер из списка по названию.

## Доступность видео и управления

Расширение работает с элементами HTML5 audio/video во вкладках и встроенных фреймах. Кадры доступны, когда браузер разрешает их чтение. Защищённое видео и некоторые ролики с другого домена закрывают чтение кадров — тогда выводится карточка с подписью «Кадр недоступен». На таких страницах команды воспроизведения могут оставаться доступными. Частота обновления зависит от браузера, сайта и модели панели. Некоторые браузеры приостанавливают декодирование видео в скрытой вкладке.

Расширение читает информацию о медиа на открытых сайтах, получает кадры выбранного видео и обменивается ими с плагином на этом ПК через `127.0.0.1`. Обложки запрашиваются у сайта с учётом ограничений браузера. Для работы пульта запускайте расширение в одном браузере одновременно.

## Если не подключилось

- **Нет связи на клавишах.** Откройте расширение и проверьте статус. Перезапустите Stream Dock. При установке в несколько браузеров отключите дополнительные экземпляры расширения.
- **Нет медиа.** Обновите вкладку после установки расширения и включите видео. Если выбран другой плеер, выберите нужный в расширении.
- **Повторяется весь кадр.** Назначьте шести кнопкам части экрана по таблице.
- **Предупреждение при перемотке.** Плеер может не поддерживать перемотку, например в прямом эфире без записи.

## Проверки для разработки

`node browser-media/tests/host.js` проверяет локальный протокол, управление и раскладку.

`python browser-media/tests/render_test.py` проверяет изображения в браузерном Worker.

`python browser-media/tests/integration.py` запускает расширение в Chromium и проверяет настоящее видео, звук, перемотку, громкость и маршрутизацию между вкладками. Нужны Node.js, Chromium, ffmpeg, Python с Playwright, aiohttp и Pillow. Если политики тестового браузера запрещают установку расширений, режим `--emulate-extension` подставляет API расширения, выполняя тот же код пульта и рендеринг в настоящем браузере. Этот режим проверяет передачу кадров и команды, а установку расширения следует проверить отдельно.
