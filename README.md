# Яндекс Музыка для Mirabox Stream Dock

Плагин добавляет шесть действий в категорию «Яндекс Музыка». Перетащите их на любые шесть клавиш панели 5×3. Боковая панель для этого не нужна.

| Кнопка | Действие |
| --- | --- |
| Текущий трек | Обновляет обложку, название и исполнителя каждые 1,5 секунды. Длинные строки сокращаются. |
| Предыдущий трек | Отправляет команду «Назад» медиасессии приложения. |
| Воспроизведение / пауза | Переключает воспроизведение. |
| Следующий трек | Отправляет команду «Вперёд». |
| Тише | Уменьшает громкость приложения на 5 процентных пунктов. |
| Громче | Увеличивает громкость приложения на 5 процентных пунктов. |

## Установка

1. На ПК с Windows 10 (1809 или новее) либо Windows 11 установите **Stream Dock 3.10.188.226 или новее**.
2. Полностью распакуйте архив. Закройте Stream Dock, в том числе в системном трее. Запустите `install.cmd` из распакованной папки. Установщик использует существующий Python 3.12 x64. Если подходящей версии нет, он запускает её установку через WinGet для текущего пользователя. Для загрузки Python и библиотек нужен интернет.
3. После сообщения «Installed» откройте Stream Dock и разместите действия на клавишах. Запустите трек в настольной Яндекс Музыке.

Если автоматическая установка Python не удалась, скачайте **Windows installer (64-bit)** со [страницы Python 3.12.10](https://www.python.org/downloads/release/python-31210/), запустите его, выберите **Install Now**, затем повторно запустите `install.cmd`.

## Если кнопки видны, но не реагируют

1. При обновлении выйдите из Stream Dock через значок в трее, распакуйте новый архив в отдельную папку и запустите из неё `install.cmd`. Дождитесь `Installed. Restart Stream Dock.` и снова откройте программу. Ранее назначенные кнопки можно использовать сразу.
2. Включите композицию в **настольной** Яндекс Музыке. Нажмите «Следующий трек» на физической панели. Карточка должна показать новую композицию. При проверке громкости смотрите на ползунок Яндекс Музыки в микшере громкости Windows.
3. Если кнопка не сработала, оставьте обе программы открытыми и дважды щёлкните по `diagnose.cmd` из распакованной папки. Отправьте файл `diagnostics.txt`, который появится рядом. В отчёте видны версия установленного плагина, события нажатия, ответ обработчика, медиасессия Яндекс Музыки и наличие доступных аудиосессий.

Windows передаёт плагину обложку, название и исполнителя через медиасессию настольного приложения. Пока в ней нет названия, карточка показывает «Нет трека». Если обложка недоступна, карточка выводит название и исполнителя на однотонном фоне. Кнопки громкости обращаются к аудиосессиям Яндекс Музыки на активных устройствах вывода.

## Проверка в облачной среде

Из корня репозитория выполните `node tests/smoke.js` в Linux. Проверка запускает настоящий модуль плагина и имитирует Stream Dock и Windows-процесс управления плеером. Команда `python tests/player_test.py` проверяет обработку медиасессий, команд и обложек с подменой интерфейсов Windows. Для сквозной проверки на устройстве запустите музыку, переключите композицию и сравните карточку с плеером. При нажатии кнопок громкости проверьте в микшере, что движется только ползунок Яндекс Музыки.
