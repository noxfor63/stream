# Яндекс Музыка для Mirabox Stream Dock

Плагин добавляет шесть действий в категорию «Яндекс Музыка». Перетащите их на любые шесть клавиш панели 5×3. Боковая панель для этого не нужна.

| Кнопка | Действие |
| --- | --- |
| Текущий трек | Обновляет обложку, название и исполнителя каждые 1,5 секунды. Длинные строки сокращаются. |
| Предыдущий трек | Отправляет команду «Назад» медиасессии приложения. |
| Воспроизведение / пауза | Переключает воспроизведение. |
| Следующий трек | Отправляет команду «Вперёд». |
| Тише | Уменьшает громкость приложения на 5 процентных пунктов. |
| Громче | Увеличивает громкость приложения на 5 процентных пунктов. |

## Установка

1. На ПК с Windows 10 (1809 или новее) либо Windows 11 установите **Stream Dock 3.10.188.226 или новее**.
2. Полностью распакуйте архив. Закройте Stream Dock, в том числе в системном трее. Запустите `install.cmd` из распакованной папки. Установщик использует существующий Python 3.12 x64. Если подходящей версии нет, он запускает её установку через WinGet для текущего пользователя. Для загрузки Python и библиотек нужен интернет.
3. После сообщения «Installed» откройте Stream Dock и разместите действия на клавишах. Запустите трек в настольной Яндекс Музыке.

Если автоматическая установка Python не удалась, скачайте **Windows installer (64-bit)** со [страницы Python 3.12.10](https://www.python.org/downloads/release/python-31210/), запустите его, выберите **Install Now**, затем повторно запустите `install.cmd`.

Если карточка показывает «Нет трека», проверьте, отображает ли Windows название трека в системном управлении мультимедиа. Для громкости выберите в микшере Windows устройство вывода по умолчанию для Яндекс Музыки. Команды громкости управляют её сеансом в микшере этого устройства. Предупреждение на кнопке означает, что соответствующий сеанс недоступен или плеер отклонил команду.

## Проверка в облачной среде

Из корня репозитория выполните `node tests/smoke.js` в Linux. Проверка запускает настоящий модуль плагина и имитирует Stream Dock и Windows-процесс управления плеером. Для сквозной проверки на устройстве запустите музыку, переключите композицию и сравните карточку с плеером. При нажатии кнопок громкости проверьте в микшере, что движется только ползунок Яндекс Музыки.
