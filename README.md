# Яндекс Музыка для Mirabox Stream Dock

В репозитории также есть отдельный **[Пульт браузера](browser-media/README.md)** с видео на шести клавишах 3×2 и управлением медиаплеерами в Opera, Chrome и Edge. Готовый архив — **[BrowserMedia-StreamDock.zip](BrowserMedia-StreamDock.zip)**.

Плагин добавляет шесть действий в категорию «Яндекс Музыка». Перетащите их на любые шесть клавиш панели 5×3. Боковая панель для этого не нужна.

| Кнопка | Действие |
| --- | --- |
| Текущий трек | Обновляет обложку, название и исполнителя каждые 1,5 секунды. Длинные строки сокращаются. |
| Предыдущий трек | Отправляет команду «Назад» медиасессии приложения. |
| Воспроизведение / пауза | Переключает воспроизведение. |
| Следующий трек | Отправляет команду «Вперёд». |
| Тише | Уменьшает громкость приложения на 5 процентных пунктов. |
| Громче | Увеличивает громкость приложения на 5 процентных пунктов. |

## Большая обложка

Разместите четыре кнопки **«Текущий трек»** квадратом **2×2**. Если на них повторяется целая обложка, в редакторе Stream Dock щёлкните по каждой из четырёх кнопок и в списке **«Часть обложки»** выберите её позицию:

| | Левая кнопка | Правая кнопка |
| --- | --- | --- |
| Верхний ряд | Верхняя левая | Верхняя правая |
| Нижний ряд | Нижняя левая | Нижняя правая |

Выбор сохраняется для каждой клавиши. Вручную назначенная клавиша показывает свой фрагмент даже без координат от Stream Dock. Название и исполнитель располагаются внизу общей картинки.

Режим «Автоматически» собирает соседние кнопки с известными координатами в заполненный прямоугольник, например 2×2 или 3×1. Одиночная кнопка показывает всю обложку. При ручной раскладке задайте части всем четырём кнопкам.

## Громкость

«Громче» и «Тише» управляют ползунком **в самой Яндекс Музыке** с шагом пять процентных пунктов. Плагин находит окно приложения через Windows UI Automation. После нажатия на клавише ненадолго появляется процент, считанный с ползунка.

Если клавиша показывает предупреждение, откройте окно Яндекс Музыки и наведите указатель на значок динамика, чтобы появился ползунок. Нажмите клавишу ещё раз. Если плеер не предоставляет ползунок, в журнале появится `NoAppVolumeSlider`. Отчёт `diagnostics.txt` содержит строку `volume app` с подтверждённым уровнем для успешных команд.

## Установка

1. На ПК с Windows 10 (1809 или новее) либо Windows 11 установите **Stream Dock 3.10.188.226 или новее**.
2. Полностью распакуйте архив. Закройте Stream Dock, в том числе в системном трее. Запустите `install.cmd` из распакованной папки. Установщик использует существующий Python 3.12 x64. Если подходящей версии нет, он запускает её установку через WinGet для текущего пользователя. Для загрузки Python и библиотек нужен интернет.
3. После сообщения «Installed» откройте Stream Dock и разместите действия на клавишах. Запустите трек в настольной Яндекс Музыке.

Если автоматическая установка Python не удалась, скачайте **Windows installer (64-bit)** со [страницы Python 3.12.10](https://www.python.org/downloads/release/python-31210/), запустите его, выберите **Install Now**, затем повторно запустите `install.cmd`.

## Если кнопки видны, но не реагируют

1. При обновлении выйдите из Stream Dock через значок в трее, распакуйте новый архив в отдельную папку и запустите из неё `install.cmd`. Дождитесь `Installed. Restart Stream Dock.` и снова откройте программу. Ранее назначенные кнопки можно использовать сразу.
2. Включите композицию в **настольной** Яндекс Музыке. Нажмите «Следующий трек» на физической панели. Карточка должна показать новую композицию. При проверке громкости откройте окно Яндекс Музыки, нажмите «Тише» и посмотрите на процент на клавише.
3. Если кнопка не сработала, оставьте обе программы открытыми и дважды щёлкните по `diagnose.cmd` из распакованной папки. Отправьте файл `diagnostics.txt`, который появится рядом. В отчёте видны версия установленного плагина, события нажатия, ответ обработчика, медиасессия Яндекс Музыки и доступность ползунка громкости плеера.

Windows передаёт плагину обложку, название и исполнителя через медиасессию настольного приложения. Пока в ней нет названия, карточка показывает «Нет трека». Если обложка недоступна, карточка выводит название и исполнителя на однотонном фоне.

## Проверка в облачной среде

Из корня репозитория выполните `node tests/smoke.js` в Linux. Проверка запускает настоящий модуль плагина и имитирует Stream Dock и Windows-процесс управления плеером. Команда `python tests/player_test.py` проверяет обработку медиасессий, команд и обложек с подменой интерфейсов Windows. Для сквозной проверки на устройстве запустите музыку, переключите композицию и сравните карточку с плеером. При нажатии кнопок громкости сравните процент на клавише с уровнем в плеере.
